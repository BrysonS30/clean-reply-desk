# Tech Stack (All Free)

- **Google Forms:** Quote request form
- **Google Sheets:** Leads, pricing, FAQ, errors log
- **Google Apps Script:** Automation: form-submit trigger, send-approved, follow-ups, weekly report
- **Gmail:** Sending replies
- **Drafting:** Rules-based drafting today. An optional AI drafting upgrade is built but turned OFF; it would only be used with the client's written OK and a paid AI service that doesn't train on their data.
